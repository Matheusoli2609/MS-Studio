## v0.2.0 — Design Language

**Data:** 25/07/2026

### Added

- Sistema oficial de Design Tokens (`tokens.css`)
- Escala tipográfica da MS Studio
- Paleta oficial de cores da marca
- Sistema de Motion
- Sistema de Spacing
- Sistema de Elevation
- Biblioteca oficial de ícones (Lucide React)

### Changed

- `variables.css` renomeado para `tokens.css`
- Padronização da nomenclatura dos Design Tokens
- Atualização do Master Roadmap para a nova fase do projeto
- Consolidação da identidade visual da MS Studio

### Resultado

A Design Language da MS Studio foi oficialmente concluída.

A partir desta versão, todas as interfaces e componentes deverão utilizar os Design Tokens e seguir as diretrizes estabelecidas pela linguagem de design oficial.
